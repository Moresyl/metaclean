# MetaClean v0.6.0

### 新功能

- 新增企业级本地 JSON 审计报告：可从文件队列导出版本、时间、处理摘要、逐文件发现项与输出状态；报告坚持“不回传原始元数据值”的隐私边界。
- HTML、XHTML、SVG 与 Markdown 会继续检查并净化内嵌 Data URI 图片，覆盖 JPEG、PNG、WebP、GIF、BMP、HEIF 和嵌套 SVG；单文件最多处理 100 张图片、单个载荷 16 MiB、递归深度 4 层。
- PDF 清理深入 JPEG 图片 XObject，移除图片内部的 EXIF/GPS、XMP、IPTC、注释与来源信息，同时保留显示方向和色彩配置。
- 音频清理新增 WAV C2PA 块与 FLAC 前置 ID3v2/C2PA 标签处理，不重新编码音频内容。

### 变更与安全

- 桌面端重构为 1180 × 720 固定企业工作台：36 像素品牌标题栏、60 像素图标导航、统一双栏工作区与 26 像素本地状态栏，清理、历史、隐私和设置页面使用同一套紧凑字阶与控件尺寸。
- 不可见文本净化扩展到全部 66 个 Unicode 非字符与保留默认忽略区间，并通过上下文规则保留合法的表情连接、复杂文字连接符、CJK 变体、旗帜标签与方向文本。
- 深层载荷继续遵循原有安全上限、格式复检与失败关闭策略；内嵌内容无法确认安全时不会被猜测性改写。
- 审计导出限制为 10 MiB JSON，并采用临时文件加原子替换，避免留下半写入报告。

### 修复与打磨

- 修复带 ID3v2 前缀的 FLAC 在进入原生清理器前被错误拒绝的问题。
- 修复漂浮的双向文本覆盖符和畸形方向控制仍可能残留的问题，同时不会破坏成对的合法嵌入或隔离序列。
- 修复仅清理 PDF、HTML 或 SVG 顶层元数据时，内嵌图片隐私块可能漏检的问题。
- 统一窗口、侧栏、标题栏、按钮、表单、面板和底部状态的视觉密度，减少旧版大小不一和信息层级松散的问题。

### 安装

- Windows x64：推荐 `MetaClean_0.6.0_x64-setup.exe`，也提供 MSI 和 `MetaClean_0.6.0_x64_portable.zip`；已安装用户可在应用内更新。
- Windows x86：提供 `MetaClean_0.6.0_x86-setup.exe` 和 `MetaClean_0.6.0_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，但 Apple 代码签名与公证仍取决于发布环境中的 Apple 凭据。
- Linux x64：推荐 AppImage，并提供配套 `.AppImage.zsync`；同时提供 DEB 和 RPM。

### English summary

- MetaClean 0.6.0 introduces a compact 1180 × 720 enterprise privacy workspace and local JSON audit exports. Its native cleaners now reach raster data URIs in markup, JPEG image XObjects inside PDFs, WAV C2PA chunks and ID3v2-prefixed FLAC streams. Unicode cleanup covers every noncharacter and reserved default-ignorable range while preserving legitimate emoji, script, CJK, flag and directional sequences contextually. All deep processing remains bounded, re-inspected and fail-closed.
