# MetaClean v0.12.4

### 新功能

- 按 MPF 索引逐帧清理多图 JPEG，重建各图的尺寸与偏移，保留图片原有顺序、类型、依赖关系和必要的视角几何信息。

### 变更与安全

- 清除 JPEG 未知 APP2、APP14 应用数据，以及已知显示结构之后附带的私有载荷。
- 保留固定颜色转换头和已验证的 ISO HDR 增益图参数；ICC 色彩配置仍遵循用户的保留选项。
- 从 HDR XMP 中仅重建已定义的显示参数，清除作者、工具标识、资源标签及其他附属信息，保留数值原始精度和通道顺序。
- 清除 MPF 图像标识、未知属性与图间私有数据，并校验所有索引图像的边界及关联；遇到不安全、冲突或不完整的结构时拒绝写入。

### 修复与打磨

- 修复多帧 JPEG 清理成功后第二帧仍被当作尾部数据删除的问题。
- 修复旧版 XMP HDR 清理后丢失显示增益参数、无法继续作为 HDR 解码的问题。
- 按清理后的实际图像重建 HDR 资源长度和必要的关联间距，兼容共享资源及图片索引顺序与存储顺序不同的情况。
- 更新桌面测试驱动的版本识别，兼容新版 Windows 驱动返回的品牌字符串。
- 扩展至 40 个独立 JPEG 验证场景，覆盖复制与替换、RGB/CMYK、双帧/三帧、单通道/三通道 XMP 参数、像素、压缩数据、配置文件、源文件及备份完整性。
- 本地另用独立 HDR 解码器验证两个 ISO 和两个旧版 XMP 样本，清理前后的完整 HDR 解码字节一致；这一结果限于这些实际样本。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Clean every indexed JPEG frame and rebuild MPF sizes and offsets while preserving image order, types, dependencies and defined view geometry.
- Remove private APP2/APP14 payloads, MPF identifiers and unindexed private data while retaining required color interpretation and validated ISO HDR parameters.
- Selectively reconstruct legacy HDR XMP rendering fields without identity metadata, retaining numeric precision and channel order; update resource lengths and shared-image associations. Refuse unsafe or conflicting structures before writing.
- Fix secondary-image loss and legacy HDR decode failure after cleanup. Update Windows desktop driver version detection.
- Expand independent JPEG qualification to 40 cases; separately verify byte-identical HDR decoding for four actual local HDR samples.
