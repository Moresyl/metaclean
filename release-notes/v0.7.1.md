# MetaClean v0.7.1

### 新功能

- 新增独立“关于”页面，直接显示当前实际运行版本、操作系统、CPU 架构、应用数据目录和程序目录；目录支持原生定位，路径可一键复制。
- 新增受限诊断信息，可复制到剪贴板或保存为 JSON。报告只包含版本、平台、架构、更新状态与应用目录，不包含已处理文件、清理历史或任何文件内容。
- 集中提供报告问题、功能建议、正式版本、源代码与 MIT License 入口，并接入侧栏、命令面板、`Ctrl/Cmd + 5` 和 macOS 应用菜单。

### 变更与安全

- “关于”页复用现有更新状态和签名更新安装流程，不引入第二套下载或安装通道；用户看到的可用版本与最终交给原生安装命令的版本保持一致。
- 保存诊断只新增必要的原生保存对话框权限；外部链接权限严格限制在 `github.com/Moresyl/metaclean` 的问题、版本、源码和许可证路径。
- 原生运行信息由当前 Tauri 二进制提供，不依赖网页包中的静态版本猜测；诊断生成逻辑与 React 页面分离，保持组件职责和热更新边界清晰。

### 修复与打磨

- 修复点击“一键更新”时前端没有向 `install_update_and_restart` 传递必需的 `expectedVersion`，从而出现 `missing required key expectedVersion` 的问题。
- 将原先设置页中不完整的“项目与支持”入口迁移到独立关于页，避免重复入口，并补齐版本、目录、诊断和社区支持信息。
- 为运行信息、诊断复制与保存、外部链接、桌面快捷键、原生命令及安全权限白名单补齐自动化回归测试。

### 安装

- Windows x64：推荐 `MetaClean_0.7.1_x64-setup.exe`，另提供 MSI 与 `MetaClean_0.7.1_x64_portable.zip`；已安装用户可使用应用内签名更新。
- Windows x86：提供 `MetaClean_0.7.1_x86-setup.exe` 与 `MetaClean_0.7.1_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，Apple 代码签名与公证取决于发布环境中的 Apple 凭据。
- Linux x64：推荐 AppImage，并提供配套 `.AppImage.zsync`；同时提供 DEB 与 RPM。

### English summary

- MetaClean 0.7.1 adds a dedicated About and diagnostics surface with runtime version, platform, architecture, application paths, bounded JSON support reports and direct project links. It fixes one-click updates by forwarding the reviewed `expectedVersion` to the native installer command, keeps all update actions on the existing signed channel, and restricts new save and opener permissions to the exact capabilities and official repository paths required. Windows x64/x86, macOS Apple Silicon/Intel and Linux x64 packages are published only after the release matrix and installer smoke tests pass.
