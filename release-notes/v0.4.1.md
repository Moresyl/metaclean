# MetaClean v0.4.1

### 新功能

- Linux AppImage 现已内嵌标准 `gh-releases-zsync` 更新信息，并随版本发布对应的 `.AppImage.zsync` 文件；AppImageUpdate、AppImageLauncher 等兼容工具可以发现 GitHub 最新版本并仅下载变化的数据块。
- 发布流水线新增二进制级阻断校验：Windows 可执行文件必须使用 GUI 子系统，Linux AppImage 必须同时包含正确的 `.upd_info` 和与本体匹配的 zsync 元数据，校验失败不会创建公开版本。

### 变更与安全

- AppImage 更新信息和 `.zsync` 在 Tauri 首次打包阶段生成，现有应用内更新使用的最终 AppImage 仍由 minisign 签名；增量更新能力不会绕过 MetaClean 的签名更新链路。
- Linux AppImage 继续支持 MetaClean 内置的检查、下载、验签、安装与重启流程，同时新增对 AppImage 生态标准增量更新工具的兼容。

### 修复与打磨

- 修复 Windows 正式版启动 MetaClean 时额外出现黑色 CMD/控制台窗口的问题；x64、x86 安装版和便携版现在都以 Windows GUI 子系统构建。
- Windows 发布任务会直接读取最终 EXE 的 PE 头确认子系统值，防止以后仅靠源码配置而意外回归。

### 安装

- Windows x64：推荐 `MetaClean_0.4.1_x64-setup.exe`，也提供 MSI 和 `MetaClean_0.4.1_x64_portable.zip`；已安装 v0.4.0 的用户可在应用内更新。
- Windows x86：提供 `MetaClean_0.4.1_x86-setup.exe` 和 `MetaClean_0.4.1_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，但不等同于 Apple 代码签名或公证。
- Linux x64：推荐 AppImage；除应用内签名更新外，发布页新增 `.AppImage.zsync` 供兼容的 AppImage 增量更新工具使用。DEB 和 RPM 继续由系统包管理器安装。

### English summary

- MetaClean 0.4.1 fixes the extra black console window on Windows by building release executables for the GUI subsystem. Linux AppImages now embed standard `gh-releases-zsync` update information and ship matching `.AppImage.zsync` metadata for block-level delta updates, while the existing Tauri/minisign in-app update path remains intact. New release gates inspect the final Windows PE header and the AppImage update metadata before publication.
