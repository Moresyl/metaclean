# MetaClean v0.12.0

### 新功能

- 更新整套界面规范：统一深浅主题、系统字体、文字层级、控件尺寸和圆角，让文件净化、历史、设置及其他页面保持一致。
- 改善紧凑窗口布局：侧栏保持可访问名称，设置导航可横向滚动，确认和更新弹窗在小视口使用完整窗口。
- 发布流水线支持选择完整提交 SHA；完成源码验证、所有平台构建及安装包冒烟测试后才创建版本标签并发布。

### 变更与安全

- 按钮统一为 28／32／36px，复选框为 18px、4px 圆角，并统一选中、禁用、未确定和键盘焦点状态。
- 保留减少动画支持，修正高对比度模式中的当前导航标识。
- 修复开发测试依赖中的两条拒绝服务漏洞路径：更新 FTP 依赖并移除有漏洞的 braces 依赖链，保持桌面测试生命周期兼容。

### 修复与打磨

- 修复动画内容限制确认弹窗定位的问题，避免遮罩只覆盖内容区域及小窗口裁掉操作按钮。
- 限定应用样式扫描范围，排除参考资料、覆盖率、原生构建和文档构建目录引起的开发缓存失效与重复刷新。
- 同步文档网站主题，新增真实桌面控件、弹窗覆盖范围及发布提交身份的回归检查。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Refresh shared themes, typography and controls, including 28/32/36px buttons and 18px checkboxes.
- Adapt compact layouts and dialogs, and render modal overlays outside animated content to prevent clipping.
- Add immutable commit selection to manual releases, with tag creation after all validation and package smoke tests.
- Remove two vulnerable development dependency paths without changing the desktop runner's Mocha lifecycle.
- Scope stylesheet scanning and development watching, and add desktop visual and release-source regressions.
