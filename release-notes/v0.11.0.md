# MetaClean v0.11.0

### 新功能

- 新增 Ogg Opus 与 Vorbis 音频清理，支持 `.opus`、`.ogg`、`.oga`，
  受支持扩展名增至 116 个；导入、音频分类与 Windows 右键菜单同步覆盖。
- 清理编码器标识和注释标签，包括作者、标题及标签内嵌封面，支持跨页长注释和连续音轨。

### 变更与安全

- 清理保持页面和数据包长度、分页表、采样位置、解码配置及编码音频字节不变，
  重新计算 Ogg 校验和；保留通过数值校验的 R128/ReplayGain 播放增益标签。
- 未知编码、损坏的页面或头部、超限注释、重复或无效增益，以及未知 Opus
  二进制扩展均拒绝处理。清理器验证容器结构，不承担完整音频解码验证。
- Linux CI 与发布门禁加入独立 FFmpeg 回归；FFmpeg 仅用于测试，应用运行无需安装。
- 新增公开发布资产校验工作流，核对下载资产 SHA-256、五个平台的更新包签名，
  并验证篡改后的包无法通过签名检查。

### 修复与打磨

- 同步全部 32 种界面的格式范围，修正波斯语旧格式计数，并加强多语言计数测试。
- 同步 NSIS/MSI 的卸载清理列表，防止新增音频扩展名留下右键菜单关联。
- 十组真实编码样本覆盖单声道、立体声、5.1、长注释和连续音轨，清理前后解码
  PCM 哈希全部一致；桌面测试覆盖三种新扩展名的导入、安全副本和输出复检。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线完成校验与安装包 smoke test 后发布资产、签名更新清单与 SHA-256 清单。
- macOS 应用尚未取得 Apple 公证；便携版通过发布页下载更新。

### English summary

- Added native Ogg Opus/Vorbis cleanup for three extensions, bringing intake and
  Explorer integration to 116 extensions. Comment cleanup preserves codec/audio
  bytes, page layout and validated numeric playback gains; unsupported structures
  fail closed.
- Ten independent FFmpeg cases verify identical decoded PCM, including surround,
  cross-page comments and chained streams. Desktop tests cover safe-copy cleanup
  and reinspection through all three extension aliases.
- Updated all 32 locale scopes and installer cleanup lists. Added independent
  public asset checksum, updater signature and tamper-rejection verification.
