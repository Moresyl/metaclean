# MetaClean v0.12.1

### 新功能

- 关于页面新增按正文容器宽度调整的布局：窄区域中的更新按钮换行，社区入口改为单列，便于阅读和操作。

### 变更与安全

- 诊断按钮和项目页脚支持换行，让同一页面的操作在紧凑内容区域内保持可见。
- 音频验证先以 600 秒预算预编译原生测试程序，随后每个原生执行和 FFmpeg 编解码步骤继续使用 120 秒限制，并保留源文件、隐私清理及音频 PCM 校验。

### 修复与打磨

- 修复关于页面内部横向滚动和操作控件超出内容边界的问题；新增中英文真实桌面回归检查，在 283px 正文区域验证内容和按钮边界。
- 文档首页根据文章容器宽度安排标题和卡片，修复 768px 视口下导航溢出，并去除整张卡片和按钮继承的下划线。
- 补齐上一版本公开安装、签名更新、回退、崩溃恢复以及音频验证修复后的实际证据。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。
