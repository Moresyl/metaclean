# MetaClean v0.7.2

### 新功能

- 原生拖放数据经过完整边界校验后，如果结构合法但没有任何可处理路径，
  现在会明确提示用户，而不是让文件像“没有拖进去”一样消失。
- 继续提供 113 个扩展名、批量队列、About/诊断、审计 JSON、签名更新和
  Windows NSIS/MSI/便携包矩阵；本版本只记录已由测试和预检证明的工程变化。

### 变更与安全

- 拖放生命周期与路径内容校验保持分离：enter/over/leave 仍可安全结束，
  drop 事件即使所有候选路径被过滤也会清除悬停状态。
- 路径、批次、诊断、报告和更新版本继续沿用原生与前端一致的字节/数量预算，
  不会因为错误反馈而把未验证路径交给扫描或清理命令。

### 修复与打磨

- 修复原生拖放包含空路径、非字符串或超长路径时的静默失败。
- 新增 App 集成回归测试，覆盖全量路径被过滤、悬停状态清理和不启动
  `expand_paths` 的行为。
- 当前版本通过 395 个前端测试、208 个 Rust 测试（另有 3 个显式忽略）、生产构建、文档构建、
  真实 Windows WebView E2E、Windows NSIS/MSI/便携包预检和 113 项右键菜单
  往返验证；具体边界见 `VALIDATION.md`。

### 安装

- Windows x64：`MetaClean_0.7.2_x64-setup.exe`、MSI 和
  `MetaClean_0.7.2_x64_portable.zip`。
- Windows x86：NSIS 安装包与 x86 便携 ZIP。
- macOS：Apple Silicon 与 Intel DMG；Linux x64：DEB、RPM、AppImage 及
  `.AppImage.zsync`。最终资产仅在各平台 smoke test、签名 updater 和
  SHA-256 清单通过后发布。

### English summary

- MetaClean 0.7.2 fixes silent native drag-and-drop failures: a structurally
  valid drop whose paths are all filtered now clears hover state and reports a
  bounded actionable error instead of silently disappearing. The release keeps
  the 113-extension native intake, signed update channel, cross-platform package
  matrix, desktop E2E and checksum gates. Rust verification reports 208 passed
  tests and 3 explicitly ignored tests. It does not claim Word/WPS application
  compatibility or Apple notarization beyond the evidence recorded in
  `VALIDATION.md`.
