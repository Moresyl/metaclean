# MetaClean v0.12.3

### 新功能

- 工具提示通过独立描述 ID 与当前控件关联，并保留控件已有的其他可访问性描述；关闭提示时只移除本次关联。

### 变更与安全

- 根据当前桌面设计规则调整普通工具提示：300px 宽度上限、12px/16px 内边距、可缩放的 8px 圆角、14px 字号、400 字重和 1.45 行高。
- 浅色与深色采用对应的浮层背景和阴影，悬停延迟为 150ms，锚点间距为 5px，视口边缘保留 15px；继续支持减少动画和系统强制色。

### 修复与打磨

- 减少动画模式直接禁用动画，让浮层立即显示最终状态，避免主题切换后已结束的极短进入动画仍留下透明或偏移的提示。
- Escape 关闭已显示或尚在等待的提示，同时保留该按键供页面或弹窗处理。
- 鼠标移出控件、窗口缩放或控件被移除时取消提示，避免悬浮说明残留。
- 工具提示挂载到文档根，按未缩放的布局尺寸定位；靠近窗口边角时仍保持可见，避免动画容器裁切及进入动画导致的测量偏差。
- 增加工具提示的交互、描述生命周期及原生浅色/深色、LTR/RTL、边角定位和真实 Escape 检查。
- 增加实际减少动画样式的原生回归，覆盖两种主题、多次挂载及四种进入效果的即时透明度、位移和动画状态。
- 保留右键菜单事件诊断及原有等待、几何和焦点断言，便于调查尚未确认原因的 macOS 菜单显示失败。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Refresh ordinary tooltips with current desktop geometry, typography, theme surfaces and viewport margins.
- Disable reduced-motion animations so entrance surfaces immediately show their final state, including after theme changes and repeated mounts.
- Associate visible descriptions with their controls while preserving existing accessibility references.
- Dismiss pending and visible tips on Escape, pointer exit, resize and control removal. Mount overlays at the document root and measure unscaled layout bounds.
- Add interaction and native theme/direction/corner regressions, retaining context-menu diagnostics and existing assertions.
