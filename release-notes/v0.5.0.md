# MetaClean v0.5.0

### 新功能

- 实际支持范围从 47 种扩展名扩展到 91 种。新增 TIFF、BMP、HEIC/HEIF/AVIF、23 种相机 RAW、AVI、Matroska/WebM、ASF/WMV/WMA 和 EPUB，并继续由原生 Rust 离线处理，不依赖 ExifTool、Perl 或 Python。
- TIFF 与相机 RAW 采用原地目录压缩；富士 RAF 在固定范围内清理内嵌 JPEG；HEIF/AVIF/CR3 按条目清零；AVI、Matroska 和 ASF 分别使用容器原生的 `JUNK`、`Void` 与填充对象。所有策略都保持媒体、条带、索引和条目偏移不变。
- 新增命令面板、自绘标题栏和适用于文件队列等区域的右键菜单；文件详情面板会显示识别格式、源文件、输出与备份路径，以及每类痕迹的处理状态。
- 新增加泰罗尼亚语、波斯语、克罗地亚语、匈牙利语、马拉雅拉姆语和越南语，完整界面语言增至 32 种；波斯语支持从右到左布局。

### 变更与安全

- Rust 引擎、前端分类、NSIS/MSI 资源管理器集成、README 格式表和支持政策统一使用 91 种扩展名清单，发布门禁会阻止任何一处发生漂移。
- 主窗口改为 1100 × 602 的无边框固定窗口，为 32 像素自绘标题栏单独增加空间，不压缩原有内容区域。
- 所有新增二进制容器都包含畸形输入、边界校验、媒体内容保持和清理后复检测试；未知格式、旧版二进制 Office、统计型文本水印和像素域水印继续失败关闭。
- EPUB 会移除作者、日期及 Calibre、Sigil、Kobo、Apple、Adobe 等工具留下的阅读器痕迹，同时保留规范要求的标识符、标题和语言，并将必需的修改时间固定到纪元值。

### 修复与打磨

- Windows 资源管理器右键菜单的安装与卸载清理扩展到全部 91 种格式，NSIS 和 MSI 清单由自动化测试逐项核对。
- 新增统一的文档级工具提示宿主，键盘焦点和鼠标悬停都能获得一致提示；窗口命令可以从标题栏、右键菜单或命令面板访问。
- 文件队列详情不显示 GPS、作者、设备标识等原始敏感值，只展示分类、数量、路径和处理结果，继续保持界面与历史记录的隐私边界。

### 安装

- Windows x64：推荐 `MetaClean_0.5.0_x64-setup.exe`，也提供 MSI 和 `MetaClean_0.5.0_x64_portable.zip`；已安装 v0.4.0 或更高版本的用户可在应用内更新。
- Windows x86：提供 `MetaClean_0.5.0_x86-setup.exe` 和 `MetaClean_0.5.0_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，但不等同于 Apple 代码签名或公证。
- Linux x64：推荐 AppImage，并提供配套 `.AppImage.zsync`；DEB 和 RPM 继续由系统包管理器安装。

### English summary

- MetaClean 0.5.0 expands the verified intake from 47 to 91 extensions with native, offset-preserving cleaners for TIFF and 23 camera RAW formats, HEIF/AVIF/CR3, BMP, AVI, Matroska/WebM, ASF/WMV/WMA and EPUB. It adds a command palette, custom title bar, application context menus, per-file cleanup details and six complete locales for a total of 32. Release gates now keep the Rust engine, frontend, Windows shell integration, published format tables and support policy synchronized while malformed input and residual metadata continue to fail closed.
