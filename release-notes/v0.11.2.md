# MetaClean v0.11.2

### 新功能

- 增加可重复执行的大文本预算边界验证：64 MiB、256 MiB 和超限一字节样例，
  校验原文件不变、输出完整内容和审计哈希。

### 变更与安全

- 文本清理改用相邻字符窗口，避免为整个文件分配完整字符数组；未改动内容按区段复制。
- 保持原有 emoji、复杂文字、CJK 变体与成对方向控制符的保留规则，
  保持 256 MiB 输入预算及安全副本工作流不变。

### 修复与打磨

- 降低大文本处理的内存开销。Windows 本机三轮合成 64/256 MiB 原生测试中，
  观察到的峰值工作集约下降 43%；256 MiB 清理从 6.1–6.3 秒降至 4.7–5.1 秒。
  测量包含夹具与哈希验证，不含桌面 WebView，也不代表所有格式、硬盘或 Unicode 组合。
- 新增原始相邻字符、嵌套方向控制符、不完整旗帜标签回归；
  108,921 组生成样例的新旧输出与发现项对照一致。
- 补充公开安装包版本转换验证流程。0.11.0/0.11.1 已通过记录的 NSIS、MSI、DEB、DMG 场景，
  包含 NSIS 应用内更新及 MSI 损坏程序修复；这些证据不能代替所有历史版本与中断恢复验证。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线通过后提供签名更新清单及 SHA-256 清单。
- macOS 尚未完成 Apple Developer 签名与公证；Word/新版 WPS 复杂文档资格仍待验证。

### English summary

- Reduce native large-text memory use with sliding Unicode context and unchanged-span
  copying while preserving the existing cleanup policy.
- Three local synthetic runs observed about 43% lower peak working set and faster
  256 MiB cleanup. These measurements exclude the desktop WebView and are workload-specific.
- Add boundary, source/output integrity and contextual Unicode regressions, plus
  repeatable published-package transition and MSI repair qualification workflows.
