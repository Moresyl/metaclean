# MetaClean v0.11.9

### 新功能

- PNG 扫描可以识别内嵌 `tIME` 修改时间，并将其列入图片元数据清理范围。

### 变更与安全

- 修复时间块此前未被报告和移除的问题，覆盖位于图片数据前后的时间块；输出复检也会拒绝残留时间块。
- 只删除这一内嵌元数据，不重新编码像素。文件系统的修改时间仍遵循“保留文件时间戳”选项。

### 修复与打磨

- 新增能在旧实现上复现漏检的回归测试。
- 使用独立图像工具验证 RGBA、调色板、16 位灰度及 APNG 动画，覆盖安全副本与替换两种模式共八项用例。
- 检查保留块、像素、透明度、色彩配置、打印分辨率、动画控制以及原文件／备份完整性；将 PNG 保真检查纳入发布门禁。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Detect and remove PNG `tIME` modification metadata before or after image data, and reject residual timestamp chunks during verification.
- Preserve all other chunks without re-encoding pixels and retain filesystem timestamps when configured.
- Add eight independent RGBA, palette, 16-bit grayscale and APNG copy/replace cases to image and release validation.
