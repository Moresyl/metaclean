# MetaClean v0.10.0

### 新功能

- 成功清理后生成原始内容与输出内容的 SHA-256 摘要，可在文件详情中展开查看。
- 历史记录保存校验摘要，审计 JSON 增加可选的 `integrity.sourceSha256` 和
  `integrity.outputSha256` 字段，方便使用独立工具核对文件内容。

### 变更与安全

- 摘要直接来自清理过程中已验证的源字节与已提交的输出字节，不在导出报告时
  重新读取可能已变化的路径。替换模式的原始摘要对应备份内容。
- IPC 与历史加载严格校验摘要格式；失败结果不提供完整性摘要，旧版记录保持兼容。
- 摘要不包含文件系统扩展属性，不是数字签名，也不证明文件之后未被修改。

### 修复与打磨

- 修复连续相对父目录被错误折叠的问题，避免不同目录的同名文件在批量队列中
  被误合并，或在扫描结果更新时被误匹配；前端与 Rust 两端同步修正。
- 增加路径边界、摘要格式、历史持久化、详情展示和审计导出回归测试。
- 真实桌面测试使用独立 SHA-256 实现核对源文件与输出文件，并检查历史与界面。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线完成校验与安装包 smoke test 后发布资产、签名更新清单与 SHA-256 清单。
- macOS 应用尚未取得 Apple 公证；便携版通过发布页下载更新。

### English summary

- Successful cleanup now records source/output SHA-256 fingerprints from the
  validated in-memory bytes. A collapsible details panel, history and optional
  audit JSON fields expose the same evidence without reopening file paths.
- Strict boundary validation retains compatibility with older reports. Hashes
  exclude filesystem attributes and are not signatures or proof of removal.
- Fixed consecutive parent-directory normalization so distinct relative files
  remain separate in intake and scan reconciliation. Added independent native
  desktop verification of file hashes, persistence and detail rendering.
