# MetaClean v0.11.6

### 新功能

- JPEG 清理保留有效的 EXIF 打印密度与单位，横向和纵向数值分别保持原有精度，
  支持英寸、厘米和无单位比例。无需重新编码图片，也不会将 EXIF 密度换算成
  精度更低的 JFIF 数值；原有 JFIF 信息保持不变。

### 变更与安全

- 只重建经过校验的数字字段，继续移除作者、GPS 等私密信息。打印密度字段
  不完整、类型无效、分母为零、重复或相互冲突时拒绝清理，不写入输出。
- 发布门禁新增十六项独立 JPEG 保真检查与六项 HEIC/AVIF 检查。JPEG 检查覆盖
  复制/替换、方向开关、非对称与小数密度、JFIF 并存、像素、ICC 和源文件/备份完整性。

### 修复与打磨

- 仅含重建方向信息的 JPEG 不再被误报为含有私密 EXIF。队列计数、筛选和清理
  按钮遵循方向保留设置；关闭该选项后，仍可移除方向信息。
- PDF 内嵌 JPEG 保留方向、打印密度和 ICC 时，不再被当作隐私残留。六项独立
  PDF 验证继续检查页面渲染、文字和表单，并增加这些图片显示信息的检查。
- 修复开发 StrictMode 下审计导出、剪贴板反馈与更新弹窗异步状态无法恢复的问题，
  同时保留离开页面后停止未开始写盘操作的保护。
- 更新 32 个语言目录的图片方向和保真说明。样本通过不等同于任意 RAW、HDR、
  打印驱动或复杂文档均已完成资格验证；现有 Rust 依赖警告仍见验证文档。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线通过后提供签名更新清单及 SHA-256 清单。
- macOS 尚未完成 Apple Developer 签名与公证。

### English summary

- Preserve exact JPEG EXIF print density, units and existing JFIF values without
  pixel re-encoding. Reject malformed, incomplete, duplicate or conflicting density.
- Treat retained orientation as informational while keeping explicit removal
  available. Preserve density, orientation and ICC in embedded PDF JPEGs without
  reporting those retained fields as private metadata.
- Add sixteen JPEG and six HEIC/AVIF release-gate cases, extend the six PDF
  cases, and fix development StrictMode async lifecycle guards.
