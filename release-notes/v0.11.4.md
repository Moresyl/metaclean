# MetaClean v0.11.4

### 新功能

- 本次为依赖维护与验证补丁，无新增用户操作。

### 变更与安全

- 将 PDF 依赖链 `lopdf → rand → chacha20` 中已撤回的 0.10.1 更新到 0.10.2。
  上游补丁修正 SSE2 随机数后端误用 SSE4.1 指令的问题；没有更改清理策略。
- 逐项记录其余 Rust 审计警告：GLib 健全性问题受 Linux GTK 依赖版本约束，
  六条维护状态警告继续跟踪。审计退出成功不代表这些风险已修复。

### 修复与打磨

- 补充公开 v0.11.3 的六轮完整桌面进程树内存测量，覆盖 64/256 MiB 文本，
  并独立校验源文件、输出和历史中的哈希；采样值不作为内存上限保证。
- 在隔离 Linux 挂载点实测空间耗尽和只读文件系统：复制与替换均安全失败，
  源文件不变，没有留下半成品、备份或临时文件。物理断电和慢盘仍未验证。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线通过后提供签名更新清单及 SHA-256 清单。
- macOS 尚未完成 Apple Developer 签名与公证；Word/新版 WPS 复杂文档资格仍待验证。

### English summary

- Replace yanked indirect `chacha20` 0.10.1 with 0.10.2, which corrects an SSE4.1
  intrinsic in the SSE2 RNG backend. Cleanup policies are unchanged.
- Document the remaining GLib soundness and six maintenance warnings with their
  dependency constraints. Add public desktop memory evidence and real isolated
  full/read-only filesystem failure tests, with their qualification limits.
