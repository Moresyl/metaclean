# MetaClean v0.4.0

### 新功能

- 安装版新增完整的应用内签名更新：可在设置页检查稳定版本、查看下载进度、安装通过签名验证的更新并自动重启。覆盖 Windows x64/x86、macOS Apple Silicon/Intel 和 Linux AppImage。
- 发布流水线新增五平台更新包与 `.sig` 收集、静态 `latest.json` 生成和完整性校验；更新包、签名与清单全部纳入 `SHASUMS256.txt`。
- Windows 便携 ZIP 新增运行时标记；便携版和 Linux DEB/RPM 会明确回退到官方 Releases 页面，不尝试覆盖正在运行或由系统包管理器管理的文件。

### 变更与安全

- 更新发现从 WebView 内的 GitHub API 请求迁移到 Tauri 原生 Rust/TLS 更新器，生产 CSP 继续只允许本地资源和 IPC，自动检查仍可独立关闭。
- 每个应用内更新都必须通过内置 minisign 公钥验证；远端清单不能关闭签名校验，也不能替换应用内信任根。
- 前端只拥有检查更新权限；下载、签名验证、安装、托盘退出协调和重启均由受限 Rust 命令负责。
- 签名只在 Release 专用 Tauri 配置中启用，私钥不进入仓库或普通本地构建；公开发布必须从加密的 GitHub Actions Secrets 取得签名材料。

### 修复与打磨

- 修复旧版更新检查在生产包中被严格 `connect-src` CSP 阻止、但模拟单测仍显示成功的问题；现在生产路径与测试路径一致使用原生更新接口。
- 新增下载字节数、总大小与安装阶段反馈；失败后保留可见错误和重试入口，并继续去重并发检查、持久化已忽略版本。
- 安装更新前再次进行原生检查；Windows 安装时安全退出托盘驻留，非 Windows 安装完成后由应用主动重启。
- 清理了既有 Rust 严格 Clippy 告警：复杂容器类型改为明确别名，Office 关系正则不再在归档循环内重复编译。

### 安装

- 从 v0.3.0 升级到 v0.4.0 需要本次手动下载安装，因为旧版生产更新检查不可用且尚未包含签名更新器；安装 v0.4.0 后，后续安装版可直接应用内升级。
- Windows x64：推荐 `MetaClean_0.4.0_x64-setup.exe`，也提供 MSI 和 `MetaClean_0.4.0_x64_portable.zip`。
- Windows x86：提供 `MetaClean_0.4.0_x86-setup.exe` 和 `MetaClean_0.4.0_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，但这不等同于 Apple 代码签名或公证。
- Linux x64：AppImage 支持应用内更新；DEB 和 RPM 继续从 Releases 下载后交给系统包管理器安装。

### English summary

- MetaClean 0.4.0 replaces the production-blocked WebView release request with Tauri's native Rust/TLS updater and adds mandatory minisign verification, download progress, install-and-restart, runtime capability detection, and safe release-page fallback for portable Windows and non-AppImage Linux packages. The five-target release pipeline now publishes signed updater artifacts and a complete `latest.json`, with every package, signature and manifest covered by SHA-256 checksums. The first upgrade from 0.3.0 remains manual; subsequent installed releases can update in app.
