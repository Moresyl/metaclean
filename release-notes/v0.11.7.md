# MetaClean v0.11.7

### 新功能

- 延续现有扫描与清理流程，本次主要改善大文件源数据复检的内存占用。

### 变更与安全

- 输出创建和替换前的源文件复检改为使用 64 KiB 缓冲区逐块精确比较，
  不再额外分配一份与源文件等大的缓冲区。仍检查完整字节、精确长度、
  链接路径和元数据；读取完成后重新读取已打开文件的元数据。
- 截断、追加、同长度篡改、权限或时间戳变化仍会阻止写入，读取错误继续向上传递。

### 修复与打磨

- 增加跨块边界、短读、读取中断、错误和恢复时间戳后的篡改测试。
- 在 Windows 独立源文件复检测量中，256 MiB 样例的观测峰值工作集从
  516.66–516.67 MiB 降至约 260.75 MiB，64 MiB 样例从
  132.66–133.11 MiB 降至 68.73–68.77 MiB；每组各三轮。
  这是复检阶段的独立测试结果，不是整个应用或任意文件的内存上限。
- 崩溃测试导出包含隐藏文件的名称、大小与哈希清单。四轮公开版复验通过，
  但强制终止仍可能绕过临时文件清理；优先使用应用内取消。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Revalidate exact source bytes using a bounded 64 KiB buffer before writing,
  retaining length, link and metadata checks without another source-sized allocation.
- Add boundary, short-read, interruption, mutation and I/O-error regressions,
  plus isolated memory measurements. Results cover revalidation only, not the
  entire application's peak memory.
- Export detailed crash file inventories and document forced-termination limits.
