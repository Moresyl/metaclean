# MetaClean v0.6.1

### 新功能

- 自动更新新增双更新源：优先读取 GitHub Release 中经过签名的 `latest.json`，主链路不可达时自动切换到官方 GitHub Pages 备用源。
- 设置页新增项目主页、Issue 反馈入口以及“关闭时退出 / 最小化到托盘”选项，关闭行为会在本机持久保存。
- 桌面界面新增统一的按钮、选择器和环境背景组件，清理队列、设置、历史、隐私页与更新对话框使用一致的交互状态。

### 变更与安全

- 更新清单发布前会校验仓库、版本、发布日期、五个平台下载地址以及每个平台的 Tauri 签名；备用源仅接受成功正式版本产生的精确签名清单。
- 安装更新前会再次核对用户已查看的目标版本；若更新源在确认后发生变化，客户端会中止安装并要求重新检查版本说明。
- 桌面视觉系统迁移到 Tailwind CSS 4 主题令牌，统一亮色/暗色配色、间距、控件高度、焦点状态和受限窗口内的滚动区域。

### 修复与打磨

- 修复无边框窗口标题栏无法拖动、最小化按钮无响应以及右上角关闭按钮无法关闭程序的问题；关闭现在默认退出，仅在用户明确启用时进入托盘。
- 修复自动更新只依赖单一 GitHub 下载链路并直接显示 `error sending request for url` 的问题；现在具有 15 秒超时、可操作的中英双语网络提示和手动下载指引。
- 修复原生更新对象和事件监听器在成功、失败或取消路径中可能未释放的问题，并改进清理操作栏、文件队列与设置内容较多时的可见性和滚动行为。

### 安装

- Windows x64：推荐 `MetaClean_0.6.1_x64-setup.exe`，也提供 MSI 和 `MetaClean_0.6.1_x64_portable.zip`；已安装用户可使用应用内自动更新。
- Windows x86：提供 `MetaClean_0.6.1_x86-setup.exe` 和 `MetaClean_0.6.1_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，但 Apple 代码签名与公证仍取决于发布环境中的 Apple 凭据。
- Linux x64：推荐 AppImage，并提供配套 `.AppImage.zsync`；同时提供 DEB 和 RPM。

### English summary

- MetaClean 0.6.1 repairs custom-titlebar dragging, minimize and close behavior, and makes exit-on-close the safe default with an optional persisted tray mode. Signed updates now use a validated GitHub Pages fallback, actionable timeout and network guidance, deterministic resource cleanup, and exact reviewed-version checks before installation. The desktop interface also adopts shared controls and a Tailwind CSS 4 token system for clearer, scroll-safe queue, settings, history, privacy, and update states.
