# MetaClean v0.12.5

### 新功能

- 扩展 WebP 隐私检查与清理，覆盖文件顶层和动画帧内的私有、未知应用扩展块。

### 变更与安全

- 清除附加 EXIF、XMP、来源标记及私有应用数据，保留压缩图像、透明通道、帧位置与尺寸、时间、混合／处置控制和循环背景设置。
- ICC 色彩配置继续遵循用户的保留选项，清理后重新校验容器与帧内残留。
- 写入前拒绝截断帧、冲突图像块、无效填充、保留位、越界画布和不匹配的动画控制信息。
- 私有／未知扩展清理可能移除应用专用编辑信息，建议先生成安全副本并检查输出。

### 修复与打磨

- 修复 WebP 报告清理成功后，顶层和动画帧内仍保留私有应用数据的问题。
- 校验声明的载荷长度，避免奇数长度加填充后被误判为有效的固定长度头。
- 新增 24 个独立 WebP 验证组合，覆盖有损／无损、透明通道、完整／偏移动画帧、复制／替换以及 ICC 保留开关；核对解码像素、压缩数据、动画参数、源文件、备份和文件时间。
- 新增七项检查器回归，确保隐私残留、次帧丢失、媒体或时间变化、错误色彩配置策略及损坏长度／填充不能被当作通过；图片与发布源流水线执行同一套验证。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Remove private and unrecognized WebP application chunks at the container level and inside animation frames while preserving compressed pixels, alpha, frame geometry, animation controls and the requested ICC policy.
- Fix false-clean results for residual private extensions and validate declared payload lengths separately from padding. Refuse malformed or conflicting animation structures before writing.
- Require 24 independent WebP fidelity cases and seven corrupt-evidence regressions in image and release source gates. Unknown extensions may contain application editing information; use safe copies and inspect outputs.
