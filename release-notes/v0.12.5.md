# MetaClean v0.12.5

### 新功能

- 扫描后可在文件详情中主动查看 DOCX/XLSX/PPTX、ODF 和 PDF 当前文档属性的实际内容，包括作者和标题；关闭预览后清除，不写入历史或审计报告。预览上限为 128 项、每项 2048 个字符，超出时提示；不提供单字段选择性删除。
- 扩展 WebP 隐私检查与清理，覆盖文件顶层和动画帧内的私有、未知应用扩展块。

### 变更与安全

- 升级 TLS 与 ZIP 处理依赖，消除本次审计发现的 7 条漏洞；更新插件锁定到上游 ZIP 修复提交，并同步 Tauri 客户端与构建工具版本。文档包声明 UTF-8 但文件名编码无效时拒绝处理，保留旧式 CP437 编码兼容性。
- 清除附加 EXIF、XMP、来源标记及私有应用数据，保留压缩图像、透明通道、帧位置与尺寸、时间、混合／处置控制和循环背景设置。
- ICC 色彩配置继续遵循用户的保留选项，清理后重新校验容器与帧内残留。
- 写入前拒绝截断帧、冲突图像块、无效填充、保留位、越界画布和不匹配的动画控制信息。
- 校验 VP8／VP8L 图像头签名、版本和尺寸，拒绝零尺寸或与画布、动画帧尺寸不一致的图像，避免损坏文件被误报为清理成功。
- 私有／未知扩展清理可能移除应用专用编辑信息，建议先生成安全副本并检查输出。

### 修复与打磨

- 中文等输入法选词期间，Enter、Esc 和方向键不再误执行命令或清空搜索；全局快捷键也尊重输入法合成状态。
- 长文档属性列表支持键盘滚动，并按实际滚动位置显示边缘提示；高对比度模式关闭装饰渐变。
- 桌面视觉回归测试兼容 125% 等非整数缩放下的物理像素取整，并避免提示框边界的浮点误差造成误报；控件设计与焦点规则保持一致。
- 修复 WebP 报告清理成功后，顶层和动画帧内仍保留私有应用数据的问题。
- 校验声明的载荷长度，避免奇数长度加填充后被误判为有效的固定长度头。
- 新增 24 个独立 WebP 验证组合，覆盖有损／无损、透明通道、完整／偏移动画帧、复制／替换以及 ICC 保留开关；核对解码像素、压缩数据、动画参数、源文件、备份和文件时间。
- 新增七项检查器回归，确保隐私残留、次帧丢失、媒体或时间变化、错误色彩配置策略及损坏长度／填充不能被当作通过；图片与发布源流水线执行同一套验证。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Update TLS and ZIP dependencies to address seven audit findings, pin the updater to its upstream ZIP fix, and align Tauri API/CLI versions. Reject invalid names declared as UTF-8 while retaining legacy CP437 support.
- Guard command/search shortcuts during IME composition and add accessible, overflow-aware scrolling cues to document-property previews.
- Make desktop visual assertions account for physical-pixel quantization at fractional display scaling and subpixel tooltip boundary arithmetic.
- Add an on-demand, read-only preview of current Office and PDF property values, including authors and titles. Values are ephemeral and excluded from history/audit exports; previews indicate truncation beyond 128 fields or 2048 characters per value. This does not select individual fields for removal.
- Remove private and unrecognized WebP application chunks at the container level and inside animation frames while preserving compressed pixels, alpha, frame geometry, animation controls and the requested ICC policy.
- Fix false-clean results for residual private extensions and validate declared payload lengths separately from padding. Refuse malformed or conflicting animation structures before writing.
- Validate VP8/VP8L coded-image signatures, versions and dimensions; reject zero dimensions or conflicts with the canvas/frame before allocating outputs or backups.
- Require 24 independent WebP fidelity cases and seven corrupt-evidence regressions in image and release source gates. Unknown extensions may contain application editing information; use safe copies and inspect outputs.
