# MetaClean v0.11.8

### 新功能

- 扩展发布前验证：可以对候选版本运行真实桌面内存测量，并记录程序哈希和进程归属证据。

### 变更与安全

- UTF-8 文本扫描和清理直接借用经过验证的输入；输出复用清理后的字符串缓冲区，减少整段文本的重复分配。
- 保留 UTF-8 BOM、UTF-16 大小端、多字节字符和原有换行。源文件复检、输出校验和审计指纹继续执行。

### 修复与打磨

- 增加借用解码、输出缓冲区复用、空文本及多字节编码的字节级回归测试。
- 三轮 Windows 原生测试进程对比中，每轮扫描并清理 64 MiB 和 256 MiB 文本，峰值工作集从 1,030.87–1,031.34 MiB 降至 518.86–519.32 MiB，源文件和输出校验全部通过。
  该结果包含原生测试的构造与校验工作，不包含桌面 UI/WebView，也不是任意文件或整个应用的内存上限。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Borrow validated UTF-8 input and reuse the cleaned output buffer while preserving encoding, BOMs and line endings.
- Add exact-byte and allocation regressions, plus candidate desktop measurement support with executable and process identity evidence.
- Three native-process comparisons reduced observed peak working sets from approximately 1,031 MiB to 519 MiB for the combined 64/256 MiB text workload. This excludes desktop UI/WebView and is not an application memory limit.
