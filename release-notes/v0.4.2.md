# MetaClean v0.4.2

### 新功能

- 侧栏与设置页现在会直接显示当前安装版本，不需要等待联网检查更新；有新版本时，顶部更新入口会明确显示目标版本。
- 新增完整的版本更新提示：展示当前版本、可用版本、发布日期和本次发布说明；选择“稍后”后只忽略当前版本，仍可从更新入口重新打开。

### 变更与安全

- 设置页重组为“外观与语言、清理偏好、系统与更新、安全保障”四个原生软件式分类，清理选项、更新状态和系统集成功能不再挤在同一页面。
- 主窗口固定为 1100 × 570，禁止最大化、拖动缩放以及键盘/滚轮页面缩放，并且只恢复窗口位置，避免旧尺寸状态破坏固定布局。
- 界面采用系统字体和更扁平的桌面控件；字号收敛为统一层级，浅色模式普通文字统一为黑色，深色模式统一为白色，警告与主操作按钮保留必要的语义色和对比度。

### 修复与打磨

- 修复 Issue #2：应用菜单现在仅在 macOS 创建，Linux AppImage 与 Windows 不再显示没有有效内容的空白窗口菜单栏。
- macOS 保留系统原生菜单，但移除了全屏入口，使固定尺寸策略在各桌面平台保持一致。
- 更新提示会打开当前版本对应的 GitHub Release，并完整显示该版本发布说明；设置页手动检查、启动自动检查和应用内签名更新能力保持可用。

### 安装

- Windows x64：推荐 `MetaClean_0.4.2_x64-setup.exe`，也提供 MSI 和 `MetaClean_0.4.2_x64_portable.zip`；已安装 v0.4.0 或更高版本的用户可在应用内更新。
- Windows x86：提供 `MetaClean_0.4.2_x86-setup.exe` 和 `MetaClean_0.4.2_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，但不等同于 Apple 代码签名或公证。
- Linux x64：推荐 AppImage，并提供配套 `.AppImage.zsync`；DEB 和 RPM 继续由系统包管理器安装。

### English summary

- MetaClean 0.4.2 fixes the empty application menu reported in Issue #2 on Linux AppImage and Windows, while retaining a native macOS menu without fullscreen. The desktop window is now fixed at 1100 × 570 with resize, maximize and WebView zoom disabled. Settings use compact native-style categories, typography and theme text colors are consistent, the installed version is always visible, and available updates show a reopenable prompt with concrete release notes and the exact GitHub Release link.
