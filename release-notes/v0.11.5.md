# MetaClean v0.11.5

### 新功能

- 支持清理使用 ASCII85 包装的内嵌 JPEG 元数据。这种 PDF 图片不再因为常见的
  ASCII85/DCT 组合被整体拒绝；处理过程不重新编码 JPEG 像素。

### 变更与安全

- ASCII85 解码限制为每个图像流 64 MiB，并检查结束标记、非法字符、分组和
  整数溢出输入。未知过滤器组合与非默认复合参数仍安全拒绝。
- 将开发测试工具链中的 `undici` 更新到 6.28.1 / 7.29.1，修复
  GHSA-3wwx-pv8p-q78v 涉及的 WebSocket 解压错误；这些依赖不属于应用运行时。

### 修复与打磨

- 修复 PDF 可填写表单字段名被当作注释作者删除的问题。合并字段与 Widget 的
  `/T` 现在保留，普通注释的作者名仍清理；真实生成的三字段样本可保留字段和值。
- 新增六组独立 PDF 保真检查，覆盖矢量与旋转页面、表单、带 EXIF 的内嵌 JPEG
  及透明矢量内容，并分别验证复制和替换模式。检查页面像素、文字、字段、图片
  元数据以及源文件/备份哈希；发布前门禁使用 Poppler 和独立解析器执行。
- 更新中英文桌面截图和操作演示。PDF 样本验证不代表所有 PDF、XFA 或数字签名
  文档均已兼容；剩余 Rust 依赖审计警告继续记录在验证文档中。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线通过后提供签名更新清单及 SHA-256 清单。
- macOS 尚未完成 Apple Developer 签名与公证。

### English summary

- Preserve merged PDF widget field names while continuing to remove ordinary
  annotation authors. Support bounded ASCII85-wrapped JPEG metadata cleanup
  without pixel re-encoding; reject malformed encodings and unsupported parameters.
- Add six independent PDF fidelity cases for copy/replace, checking rendered
  pixels, text, forms, JPEG EXIF and source/backup integrity in the release gate.
- Patch development-only undici dependencies for GHSA-3wwx-pv8p-q78v and refresh
  bilingual desktop illustrations. Complex PDF compatibility remains unqualified.
