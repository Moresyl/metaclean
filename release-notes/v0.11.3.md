# MetaClean v0.11.3

### 新功能

- 增加真实清理中断回归流程：导入 64 个合成文本文件，执行扫描和确认清理，
  在生成部分副本后强制结束进程，再检查源文件、已完成输出及两次重启行为。
  同一流程可以验证候选构建和公开便携包。

### 变更与安全

- 清理开始前在本机写入并刷新不含文件路径的原生恢复记录；写入失败时不开始修改文件。
- 用文件锁区分仍在运行的任务，避免另一个应用实例消费活动记录。
- 桌面测试工具链的间接依赖 `ip-address` 固定到 10.5.1，修复地址范围分类问题；
  该依赖属于开发和测试工具，不属于应用前端运行依赖。

### 修复与打磨

- 修复强制结束清理进程后可能没有重启提示的问题。此前仅依赖 WebView 存储标记，
  v0.11.2 的真实中断测试两次复现提示缺失。
- 正常完成或取消时删除原生记录；异常退出后提示重新导入并扫描，
  不恢复路径、不自动继续文件操作，提示在消费后不再重复。
- 补充活动批次隔离、损坏记录、不可写目录、前端响应校验及重复初始化回归。
- Windows x64 候选已通过 64 文件真实中断验证：源文件与已完成副本哈希一致，
  首次重启提示中断、第二次不再重复，两次均未自动恢复写操作。
  该修复不代表断电或安装器中断恢复已获验证。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线通过后提供签名更新清单及 SHA-256 清单。
- macOS 尚未完成 Apple Developer 签名与公证；Word/新版 WPS 复杂文档资格仍待验证。

### English summary

- Persist a path-free native interruption marker before cleanup, and use file locks
  to distinguish active batches from abandoned ones. Normal completion removes it;
  restart consumes abandoned records once without restoring paths or resuming work.
- Fix missing restart notices reproduced by forcibly terminating v0.11.2 during
  real cleanup. Add candidate/public-package crash regression and recovery tests.
- Pin the development-only `ip-address` dependency to 10.5.1 for address-classification
  security fixes. Power-loss and interrupted-installer recovery remain unqualified.
