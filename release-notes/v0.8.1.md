# MetaClean v0.8.1

### 新功能

- Windows NSIS 与 MSI 安装界面使用统一的产品图标和中性配色素材，
  NSIS 卸载页同步使用产品页眉；安装素材具有尺寸、格式和配色校验。
- NSIS 根据 Windows 显示语言自动使用简体中文或英文，采用清晰的中文
  字体，并记住安装时的语言，避免卸载时再次弹出语言选择。

### 变更与安全

- 优化深浅主题的背景层次、辅助文字对比度和分隔线；焦点及勾选状态使用
  蓝色，按钮统一为 28/32/36px，输入控件统一为 32px。
- 简化侧栏、标题栏与设置页，设置项使用分隔行；空队列仅显示一个文件
  导入区域，添加文件后才展示队列，清理按钮始终固定在选项区底部。
- 文档站采用统一的视觉样式，中英文 README 与使用指南更新为真实桌面
  截图；文档部署继续保留签名更新清单的固定地址。
- 文件处理仍在本机执行，继续使用只读扫描、安全副本、备份、候选复检、
  原子写入和签名更新验证。

### 修复与打磨

- 修复文档导航图标未被包含在站点构建产物中的问题。
- 为发布后更新清单的可用性增加有限重试，避免清单尚未传播完成时导致
  文档与备用更新源部署失败。
- 清理非 Windows 原子写入代码的未使用变量警告，保持原有替换和权限逻辑。
- 本地通过 397 项前端测试、13 项真实桌面端到端测试、40 项发布检查，
  前端四项覆盖率均超过 80%；额外检查深浅主题和原生桌面截图。

### 安装

- Windows x64 提供 `MetaClean_0.8.1_x64-setup.exe`、MSI 和便携 ZIP；
  Windows x86 提供 NSIS 安装程序与便携 ZIP。
- macOS 提供 Apple Silicon 和 Intel DMG；Linux x64 提供 DEB、RPM、
  AppImage 与增量更新元数据。发布附件同时包含签名更新清单和 SHA-256
  校验文件，所有平台打包与启动检查通过后才公开。
- macOS 应用尚未取得 Apple 公证；便携版通过发布页下载更新。

### English summary

- MetaClean 0.8.1 refines dark/light contrast, focus and checked states, button
  sizing, navigation, empty-state intake and divided preference rows. Cleanup
  actions remain pinned and the queue appears after files are added.
- Windows installers and uninstall screens receive unified product artwork;
  NSIS supports automatic Chinese localization, readable CJK text and remembered
  uninstall language. Documentation gains a fresh native screenshot and its
  missing navigation logo, while bounded manifest retries improve deployment.
- Local validation passed 397 frontend tests, 13 desktop E2E scenarios and 40
  release checks. Processing remains local with verified writes and signed
  updates; macOS notarization is not claimed.
