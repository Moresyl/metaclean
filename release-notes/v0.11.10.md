# MetaClean v0.11.10

### 新功能

- JPEG 检查现在可识别 APP0 中的内嵌缩略图、JFXX 预览及应用私有数据，并将其列入图片元数据清理范围。

### 变更与安全

- 清理 JFIF 缩略图和尾随私有数据，移除 JFXX 及其他应用私有 APP0 段，避免旧预览或编辑器标识随图片一起分享。
- 精确保留 JFIF 版本、分辨率单位、横纵密度与像素比例，不重新编码主图压缩数据。
- 截断的 JFIF 显示头、缩略图像素或不一致的缩略图尺寸会被拒绝；输出复检会拒绝残留 APP0 隐私载荷。

### 修复与打磨

- 新增能在旧实现上复现漏检的回归测试，并覆盖显示信息保留和无效输入。
- 扩展十六项独立 JPEG 保真用例，加入 RGB 缩略图、JPEG／调色板／RGB JFXX 预览及应用私有数据。
- 覆盖安全副本与备份后替换、方向保留开关和四组密度场景，核对主图压缩字节、解码像素、ICC、方向、打印密度及源文件／备份完整性。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Detect and remove JPEG APP0 embedded thumbnails, JFXX previews and application-private data, including trailing private bytes inside JFIF segments.
- Preserve exact JFIF version, resolution units, densities and pixel aspect ratio without re-encoding the main image.
- Reject truncated JFIF headers and thumbnail payloads, and reject residual APP0 privacy payloads during output verification.
- Extend sixteen independent JPEG copy/replace fidelity cases with RGB, JPEG and palette previews, private sentinels and exact compressed-scan checks.
