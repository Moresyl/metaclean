# MetaClean v0.8.0

### 新功能

- 新增可折叠工作区侧栏：展开时提供 264px 的分组导航与快捷键提示，
  收起后保留 64px 图标导航和完整无障碍名称。
- 侧栏状态会在本机持久化，并可通过标题栏按钮、命令面板或
  `Ctrl/Cmd+B` 切换；原有 `Ctrl/Cmd+1…5` 页面导航保持不变。

### 变更与安全

- 更新器传输依赖已升级到 `rustls 0.23.45`，修复
  `RUSTSEC-2026-0285` 所述的 TLS 1.3 握手消息校验问题。
- 桌面框架改为连续的中性工作区表面，深色、浅色和跟随系统主题共享
  14px 基础字阶、紧凑控件和独立的成功、警告、危险语义色。
- 固定窗口仍为 1180 × 720；标题栏调整为 44px，状态栏保持 26px，
  发布一致性测试会阻止界面布局与 Tauri 窗口配置发生漂移。
- 所有文件处理继续完全在本机执行；本版本没有放宽 CSP、路径预算、
  候选复检、原子写入或签名更新边界。

### 修复与打磨

- 修复侧栏展开或收起时原生最小化与关闭按钮未始终贴齐窗口右侧的问题。
- 移除导航背景装饰，统一卡片、输入框、选中态和分隔线的层级；动画限制在
  100–200ms 的颜色、透明度和几何变化，并继续遵循系统减少动态效果设置。
- 新增侧栏持久化、快捷键和标题栏切换回归测试；完整前端测试为 397 项，
  四项覆盖率指标均高于 80%。

### 安装

- Windows x64：`MetaClean_0.8.0_x64-setup.exe`、MSI 和
  `MetaClean_0.8.0_x64_portable.zip`；Windows x86 提供 NSIS 与便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM、
  AppImage 及 `.AppImage.zsync`。资产仅在对应 smoke test、签名 updater
  清单和 SHA-256 校验通过后公开。

### English summary

- MetaClean 0.8.0 adds a persistent, keyboard-accessible 264/64px workspace
  sidebar and refines the fixed desktop shell with neutral high-contrast themes,
  compact controls and a 14px base type scale. Caption controls remain anchored
  to the window edge, motion respects reduced-motion settings, and the local-only
  processing, bounded input, atomic-write and signed-update guarantees remain
  unchanged. The release does not claim Word/WPS compatibility or Apple
  notarization beyond the evidence recorded in `VALIDATION.md`.
