# MetaClean v0.7.0

### 新功能

- 新增原生 JPEG XL 清理：容器中的 EXIF、XMP、JUMBF/C2PA、Brotli 包装元数据与 JPEG 重建数据会被原位作废，码流及分片位置不移动；裸码流会被识别并逐字节保留。
- 新增 AIFF/AIFC 原生清理，可移除名称、作者、版权、注释、评论、ID3、XMP 与 C2PA，不重新编码音频采样。
- OpenDocument 支持扩展到 11 种 ODF 文档与模板扩展名，覆盖属性、批注、修订、可选设置及加密元数据拒绝；真实应用入口现已统一支持 105 种扩展名。

### 变更与安全

- 所有输入读取限制为 256 MiB，拒绝符号链接与 Windows 重解析点；覆盖原文件前会重新读取并核对源内容，副本与备份使用不覆盖现有文件的原子创建，消除检查后写入竞态。
- 批量请求、目录遍历、ZIP/XML/PDF 展开、嵌套容器与递归处理均加入严格预算；扫描器或清理器单文件异常会被隔离，不会中止整个批次或泄露内部解析状态。
- JPEG、PNG、WebP、HEIF/AVIF、TIFF/RAW、BMP、GIF、MP3、FLAC、AVI、ASF、PDF、Office 及嵌入图片全面加强结构校验；遇到截断、重叠、重复、歧义或容器计数不一致时会安全拒绝，不写出无法证明正确的文件。
- 清理候选内容在选择输出路径、创建备份或写盘前会重新识别格式并完整复扫；任何残留隐私痕迹或格式漂移都会阻止提交。

### 修复与打磨

- 修复原生扫描/清理返回缺失、重复或夹带无关路径时可能错误完成队列的问题；未返回结果的文件会保持可重试，失败清理也可再次执行。
- 修复快速双击可能在 React 重绘前启动两次操作，以及重新扫描时沿用旧报告或旧输出结果的问题。
- 修复 localStorage 被禁用、超限或含损坏 JSON 时可能影响应用初始化的问题；历史记录会验证嵌套结构并只保留最新 100 条。
- 补齐 OpenDML AVI 链、渐进式 JPEG 扫描后的私有段、PNG 顺序与 CRC、WebP 扩展头、HEIF item extent、APEv2/ID3 footer、PDF 嵌入 JPEG 过滤器以及 Office 混合大小写部件的处理或安全拒绝。

### 安装

- Windows x64：推荐 `MetaClean_0.7.0_x64-setup.exe`，另提供 MSI 与 `MetaClean_0.7.0_x64_portable.zip`；已安装用户可使用应用内签名更新。
- Windows x86：提供 `MetaClean_0.7.0_x86-setup.exe` 与 `MetaClean_0.7.0_x86_portable.zip`。
- macOS：分别提供 Apple Silicon 与 Intel DMG；更新包具有 MetaClean 更新签名，Apple 代码签名与公证取决于发布环境中的 Apple 凭据。
- Linux x64：推荐 AppImage，并提供配套 `.AppImage.zsync`；同时提供 DEB 与 RPM。

### English summary

- MetaClean 0.7.0 expands its native, no-reencoding contract to 105 extensions with JPEG XL, AIFF/AIFC and the full OpenDocument family. It adds bounded no-follow input reads, no-clobber outputs, source-change guards, per-file panic isolation and stricter structural verification across image, audio, video, PDF, Office and embedded-image cleaners. Queue reconciliation, retry behavior and browser-storage recovery are hardened so missing or malformed native responses and persisted data fail safely. Windows x64/x86, macOS Apple Silicon/Intel and Linux x64 packages are produced only after the release matrix and installer smoke tests pass.
