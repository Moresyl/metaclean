# MetaClean v0.12.6

### 新功能

- 本次为键盘可访问性维护版本，改进更新弹窗关闭后的操作衔接，不增加新的文件处理格式。

### 变更与安全

- 崩溃恢复验证记录页面身份与启动时间，帮助区分真正重启的页面和旧连接；此项是验证工具改进，不代表已经解决此前偶发提示的原因。

### 修复与打磨

- 打包前清理缓存中残留的旧版本安装包，防止多版本产物混入导致发布校验失败；保留编译缓存与产物唯一性检查。
- 修复更新弹窗关闭后焦点可能落回页面主体、键盘操作失去明确位置的问题。当原按钮已被移除、禁用，或弹窗打开前没有可用焦点时，回到主工作区；原控件仍可用时继续返回原控件。
- 增加三类焦点回归检查。本地 466 项前端测试通过，并在实际 Windows WebView 中检查长更新说明的 Tab、Home、End 操作，以及标准和紧凑窗口下的明暗主题布局。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux 提供 DEB、RPM 和 AppImage。
- 内置更新校验签名。macOS 安装包尚未完成 Apple 签名与公证。

### English summary

- Clear stale bundled installers before packaging while retaining compilation caches and strict asset uniqueness checks.
- Restore keyboard focus to the main workspace when an update dialog closes without a usable original control; retain normal focus return when the opener remains available.
- Add regressions for removed, disabled and absent openers. Local frontend tests total 466; native Windows checks cover long-note keyboard scrolling and both themes at standard and compact viewport sizes.
- Record page identities and time origins in crash-recovery verification. This diagnostic change does not claim to resolve the previously observed intermittent notice behavior.
