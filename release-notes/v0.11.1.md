# MetaClean v0.11.1

### 新功能

- 增加 Office VML 批注形状检测，输出复检可识别只剩形状、没有批注 XML 的残留。

### 变更与安全

- 仅删除 Excel 命名空间中 `ClientData ObjectType="Note"` 对应的 VML 形状，
  共用 VML 文件内的按钮、普通绘图和其他内容保持原样。
- 未声明的命名空间、畸形属性、未闭合或嵌套的形状、缺少所属形状的批注均拒绝处理。
- 外部 Office 样例回归增加原文件字节不变和清理结果无残留断言。

### 修复与打磨

- 修复 v0.11.0 清除 XLSX 批注 XML 后，WPS 仍会根据遗留 VML 形状重建空批注的问题。
- WPS Office 2019（11.8.6.11825）三个原创 OOXML 样例通过清理、打开、另存和再次读取：
  DOCX 正文及表格、XLSX 公式与计算结果、PPTX 两页文字保留，批注移除，源文件哈希不变。
  这属于样例语义验证，不代表所有版本、复杂对象和版式均已认证，也不是 Microsoft Word 验证。
- 公开能力审计按源码、测试和发布证据描述能力与限制；路线图同步发布事实，
  文档门禁增加版本与支持格式数量的一致性检查。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM 和 AppImage。
  发布流水线通过后提供安装包、签名更新清单和 SHA-256 清单。
- macOS 应用尚未取得 Apple 公证；便携版通过发布页下载更新。

### English summary

- Remove residual VML note shapes that caused WPS to reconstruct empty XLSX
  comments, preserving shared controls and ordinary drawings. Malformed note
  structures fail closed, and residual inspection now covers VML parts.
- Verified synthetic DOCX/XLSX/PPTX semantic round trips in WPS 2019 11.8.6.11825,
  preserving table cells, formulas, slide text and original file hashes. This is
  limited sample evidence, not general layout or Microsoft Word certification.
- Strengthened external Office assertions and documentation consistency checks,
  and replaced public comparisons with a factual capability audit.
