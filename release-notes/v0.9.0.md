# MetaClean v0.9.0

### 新功能

- 队列支持搜索文件名、原始路径、输出路径和备份路径。搜索会归一化全角
  字符、大小写与路径分隔符，便于从批量文件中定位目标。
- 新增待清理项和失败项筛选、匹配数量、无结果提示与清除筛选操作；
  搜索框中按 Escape 可重置。待清理筛选遵循当前 ICC 与 macOS 扩展属性
  选项，并排除已清理成功的文件。
- 新功能文案覆盖全部 32 种界面语言。筛选时明确提示：它只改变显示，
  扫描、清理、复制全部路径和审计导出仍针对整个队列。

### 变更与安全

- 重新整理深浅主题层次、中文标题字重、40px 导航行和圆角导入面板；
  添加文件类型图标，清理选项改用轻量分隔结构，主要操作保持固定可见。
- 英文 README 使用英文实机截图，中文 README 使用中文实机截图，补充
  扫描结果、浅色工作区、偏好设置及播放两轮的真实流程 GIF。
- 文档截图由独立脚本使用合成文件生成，调用原生扫描与安全副本流程，
  验证原文件保留、清理副本移除痕迹；脚本恢复偏好并清除临时文件。
- 文件处理继续完全在本机执行，保持备份、候选复检、原子写入和签名更新。

### 修复与打磨

- 修正默认窗口下英文清理选项的滚动溢出，以及筛选下拉框标签被截断的问题。
- 为文件名归一化、输出路径搜索、保真选项筛选、失败状态、空结果恢复和
  完整队列复制范围添加回归测试；前端 401 项测试通过，四项覆盖率均超过 80%。
- 桌面测试增加真实文件导入、搜索、扫描和安全副本清理验证，并显式设置
  测试语言，避免受上一次截图会话影响。

### 安装

- Windows x64 提供 NSIS、MSI 和便携 ZIP；Windows x86 提供 NSIS 和便携 ZIP。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x64 提供 DEB、RPM、AppImage
  和增量更新元数据。全部平台检查通过后发布安装包、签名更新清单和 SHA-256。
- macOS 应用尚未取得 Apple 公证；便携版通过发布页下载更新。

### English summary

- MetaClean 0.9.0 adds normalized queue search across names and source/output/
  backup paths, actionable-finding and failure filters, empty-result recovery and
  Escape reset. All 32 locales include the new copy; batch actions retain their
  full-queue scope and the UI states this explicitly.
- Refined surfaces, typography, navigation, file-type glyphs and cleanup options
  accompany language-matched native screenshot galleries and finite-loop GIFs.
  The capture workflow uses synthetic files and verifies actual native cleanup.
- Added regression coverage and a real desktop intake/search/scan/safe-copy
  scenario. Frontend validation passes 401 tests with all coverage metrics above
  80%. Local processing and signed update boundaries remain unchanged.
